# Che

Cliente de correo para Mac, con la organización de Hey: Imbox, The Feed, Paper Trail y Screener.

Este repositorio solo tiene los instaladores y el archivo que la app usa para actualizarse sola. El código es privado.

## Instalar

1. Descargá el `.dmg` de la [última versión](https://github.com/jsteckler/che-releases/releases/latest).
2. Abrilo y arrastrá Che a Aplicaciones.
3. La primera vez, macOS avisa que no puede verificar al desarrollador. Abrí **Ajustes del Sistema → Privacidad y seguridad** y tocá **Abrir de todos modos**.

Después Che se actualiza sola. Cuando haya una versión nueva, al reiniciar la app te puede pedir permiso para usar tus contraseñas guardadas: elegí **Permitir siempre**.

Requiere macOS 13 o posterior (Apple Silicon o Intel).
